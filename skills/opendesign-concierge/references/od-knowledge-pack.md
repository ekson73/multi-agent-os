## What it is
- `nexu-io/open-design` · **65.3k⭐** · **Apache-2.0** · the open-source, **agent-native, local-first** design platform ("Figma / Claude-Design alternative"). Turns coding agents (Claude Code, Codex, Cursor, Gemini, OpenClaw, …22+) into design engines.
- **BYOK — no local LLM required.** Uses the host agent's own model/keys. The **AMR (Agentic Model Router)** is an optional **paid** model service (`open-design.ai/amr/`) — NOT required.
- Monorepo (pnpm): `apps/` (daemon=`od` bin + web Next.js + Electron desktop), `packages/`, `design-systems/`, `design-templates/`, `craft/`, `plugins/`, `skills/`.
- **Canonical clone already on disk** at `~/.claude/plugins/marketplaces/open-design/` → **do not reinstall / re-clone.**

## `od` CLI surface (verified vs `apps/daemon` source)
| Command | Syntax | Purpose |
|---|---|---|
| apply a plugin | `od plugin apply <id> [--project <projectId>] [--input k=v ...] [--grant-caps <caps>] [--json]` | run a design plugin scenario. Ex: `od plugin apply make-a-deck --input topic="x" --json` |
| list skills | `od skill list [--scenario <s>]` | enumerate available skills |
| install MCP | `od mcp install <agent> [--name <label>] [--json] [--dry-run] [--uninstall]` | wire the OD MCP server into an agent (claude, codex, cursor-agent, …) |
| code migration | (via `od plugin apply` with `taskKind: "code-migration"`) | "point at a git repo + DESIGN.md → get a PR" — refresh an existing codebase to a brand spec |

> The `od` bin is `apps/daemon/bin/od.mjs`; running it from source needs `pnpm --filter @open-design/daemon build` first (Node ~24 / pnpm 10.33). **Easier: install via Docker** (`deploy/scripts/install.sh` — Docker is the only prerequisite, no node/pnpm build).

## MCP (Claude Code)
- Transport: **stdio / local-path** (subprocess). Requires a **local/source install** for now — "Container-friendly MCP transport will be added in a follow-up" (`docs/install-guide.md`).
- Install: `od mcp install claude`.
- ⚠️ **The exact MCP config snippet is auto-generated by the Open Design Settings UI** based on daemon presence — it is NOT a hard-coded string in the docs. Do not fabricate it; run `od mcp install claude` (or copy it from Settings) rather than hand-writing `~/.claude.json`.

## A design-system `DESIGN.md` (the brand contract)
- 9-section schema: Visual Theme · Color · Typography · Spacing · Layout · Components · Motion · Voice · Anti-patterns.
- Each ships a package: `DESIGN.md` + `tokens.css` (`:root{}` CSS vars) + `tailwind-v4.css` + `design-tokens.json` + `components.html` + `components.manifest.json` + `USAGE.md` + `preview/`.
- **Programmatic application** (not just GUI): a skill declares `od.design_system.requires: true` (+ optional `od.design_system.sections: [color, typography]` to prune context); the daemon reads the selected `design-systems/<slug>/DESIGN.md`, extracts the `:root{}` tokens, and **injects them into the system prompt** before launching the agent (agent reads tokens as plain text — no programmatic token API). Optional `od.craft.requires: [typography, color, anti-ai-slop]` injects matching `craft/*.md` between the DESIGN.md and the skill body.
