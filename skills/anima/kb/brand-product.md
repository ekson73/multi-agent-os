# Adapter — brand / product (product · brand · startup · app · service · domain · package)

> ⚠️ **HUMAN_DOMAIN flag (SKILL §0)**: a brand/domain/trademark/package name is a legal + commercial commitment.
> This adapter pronounces a recommended name but **flags it `[HUMAN_DOMAIN: ratify]`** — never auto-registers a
> domain/package/trademark. It is a *pre-screen*, not legal clearance.

## Method (borrowed + cited — DRY with external craft, not reinvented)
1. **Strategy first** (Placek *Diamond Framework*, Lexicon Branding): lock the ONE idea the name must carry before
   generating — domain → vision → advantage → gap → message. A messy brief makes messy names.
2. **Seeds + sound**: extract literal + evocative seed words; set a target *sound profile* using sound-symbolism
   (bouba/kiki — soft phonemes feel calm/round, hard plosives feel fast/sharp). Match sound to the desired feeling.
3. **Generate** broadly (judgment off): cross-cultural roots (Latin/Greek/Sanskrit), morpheme blends, compounds,
   sound-symbolic coinages, industry-vocab remixes.
4. **Score** with the 12-aspect scorecard + Placek's 3 pillars (trust · originality · accessibility).
5. **Availability/collision pre-screen (§5)**: web-search each finalist for existing products; check domain + package
   registry + social handle + a rough trademark gut-check. CLEAR / CAUTION / BUMP each.

## Coinage rule (anti-theater R4)
Coined tokens are allowed **labeled as coinages** with their constructed etymology stated (e.g. "*Vercel* ← *inverse*
+ *cell*"). Never present a coinage as a pre-existing dictionary word.

## Worked example
Subject: *"B2C fintech app, trust-forward, BR market"* → strategy idea = *calm trust*; sound = soft onset.
→ pre-screen finalists for `.com.br` + app-store + trademark → **decide one** + `[HUMAN_DOMAIN: ratify]` + risk flag.
