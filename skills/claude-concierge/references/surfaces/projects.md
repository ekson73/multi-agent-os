# Surface: Projects (claude.ai)

> Load only when the intent is about Projects on claude.ai. Verified 2026-10-26.

- **What it is:** workspaces with their own chat history and knowledge base.
- **Customization:** project instructions + project knowledge; retrieval (RAG) on paid plans; sharing on Team/Enterprise. The free plan is limited to five projects. The page also mentions a beta of Projects based on Claude Code.
- **Compare:** a Project holds knowledge for chats; a Claude Code repo holds `CLAUDE.md`/`AGENTS.md` + skills for coding. Pick by where the work runs.
