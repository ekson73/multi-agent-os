# Surface: Projects (claude.ai)

> Load only when the intent is about Projects on claude.ai. Verified 2026-10-26.

- **What it is:** workspaces with their own chat history and knowledge base.
- **Customization:** project instructions + project knowledge; retrieval (RAG) on paid plans; sharing on Team/Enterprise. The free plan is limited to five projects.
- **Not the same as Claude Code Projects (beta):** a separate feature in claude.ai/code and the desktop Code tab — one ongoing conversation that runs related tasks as parallel threads, usually cloud Claude Code sessions. Public beta on Pro and Max, rolling out gradually; not on Team/Enterprise. Ask which one the user means before answering.
- **Compare:** a chat Project holds knowledge for chats; a Claude Code repo holds `CLAUDE.md`/`AGENTS.md` + skills for coding; a Claude Code Project groups parallel coding threads. Pick by where the work runs.
