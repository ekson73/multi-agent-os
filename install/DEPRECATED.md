# DEPRECATED

This directory is deprecated as of v1.0.0.

## Migration

Installation is now handled via the Claude Code plugin system (plugin name: `maos`). See [`README.md`](../README.md#installation) for full instructions.

```text
# From the plugin marketplace (inside a Claude Code session).
# Replace <owner>/<marketplace-repo> and <marketplace> with the values in
# README.md#installation (canonical) or with your fork's own marketplace.
/plugin marketplace add <owner>/<marketplace-repo>
/plugin install maos@<marketplace>

# Or load locally from source (shell)
claude --plugin-dir /path/to/multi-agent-os
```
